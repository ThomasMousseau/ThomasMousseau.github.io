## 1. Vanilla Attention


| Category &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | Symbol &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | Shape &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; | Description |
| :--- | :--- | :--- | :--- |
| **Parameters** | $W_Q, W_K$ | $d_{\text{em}} \times d_k$ | Query and Key projection weights |
| | $W_V$ | $d_{\text{em}} \times d_v$ | Value projection weights |
| | $W_O$ | $d_v \times d_{\text{em}}$ | Output projection weights |
| **Projections** | $X$ | $\text{seq} \times d_{\text{em}}$ | Input token embeddings |
| | $Q, K$ | $\text{seq} \times d_k$ | Projected queries and keys |
| | $V$ | $\text{seq} \times d_v$ | Projected values |
| **Intermediates** | $A$ | $\text{seq} \times \text{seq}$ | Attention scores |
| | $O$ | $\text{seq} \times d_v$ | Weighted value aggregation |
| | $\Delta X$ | $\text{seq} \times d_{\text{em}}$ | Attention update projected back to embedding space |
| | $X_{\text{attn}}$ | $\text{seq} \times d_{\text{em}}$ | Attention output after residual addition |
