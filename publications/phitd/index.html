Distributional Reinforcement Learning using Characteristic Functions

Thomas Mousseau, Tyler Kastner, Davide Baldelli, Amir-massoud Farahmand

NeurIPS 2026arXivGitHub

IntroApproachResultsTakeaways

Intro

An agent acts, gets a reward, and has to decide what to do next.

Two actions can share the same expected return while carrying different risks.

The return distribution keeps the shape that a single mean throws away.

Distributional RL learns the full return distribution.

Categorical and quantile methods stay tractable by staying inside a discrete family.

When a target value falls between grid points, categorical projection splits its probability mass between its neighbors.

Putting the Bellman target back on the grid changes the distribution and introduces error.

The update leaves the family. A projection operator pulls the target back in.

Can we learn richer return distributions without that explicit projection?

Approach

One sound can be read as a wave in time, or as a set of frequencies.

A characteristic function is the same idea for a distribution: all of its frequencies.

In frequency space, the target stays in the same function space. No projection step.

The distance between two distributions has a closed form there. In practice, sample frequencies.

Results

The family that matches the target is the one with the lowest error.

The same idea, trained on Craftax for a billion steps.

Takeaways

Distributional RL, without explicit projection error, from a frequency-domain view.
